## SISTEMA DE INFORMAÇÃO

 ## introdução

  # O QUE É UM SISTEMA


   Um sistema é um conjunto de partes que trabalham em conjunto para atingir um objetivo 

   possui 3 etapas:

   ENTRADA:
   dados ou recursos que entram no sistema

   PROCESSO:
   transformação de dados em algo util

   SAIDA:
   resultado ou produto final

 # O que é um Sistema de Informação

  Sistema que coleta, armazena e distribui informações para apoiar decisões e controle em uma organização.

 # O QUE É UM DADO

  Dado = fato bruto, sem contexto ou significado. por si só, o dado não diz nada.
  Exemplo de dados brutos: 27

 # informações e conhecimento

  Dado: dado bruto sem contesto
  Informação: dado com significado
  Conhecimento: Informação aplicada com experiencia

 # Sistema no dia a dia

  App de banco: Consulta, saldo, faz transferencia, paga boletos
  E-comercio: Compra online, restrear pedidos, sugestão de produtos 
  Saúde digital: agenda de comsiçtas. acessa , prontuarios, exames online
  Plataforma EAD: assiste aulas, faz provas, recebe certificados
  Redes sociais: compartilha, reage e recebe conteudo personalizado
  Sistema de transito: GPS, Semaforos inteligentes, Rotas em tempo real

 # TIPOS DE SISTEMA DA INFORMAÇÃO
  TPS: Sist. de procesamento de transações

  MIS: Sist de informação gerencial

  DSS: Sist. de suporte a descisão

  EIS: Sist. de informação executiva

  ERP: Planejamento de recursos empresariais
 
 # PAPEL DO PROGRAMADOR DE SISTEMAS

  Desenvolver: Criar os programas e módulos do sistema
  Entregar dados: conectar bancos de dados a API´s
  Manter: corrigir erros e atualizar funcionalidades
  Entender o negocio: Tradizir o que os clientes desejam em codigos
  Testar: Garantir que o sistema funcione corretamente por meio de testes
  Documentar: Registrar como o sistema foi contruido
