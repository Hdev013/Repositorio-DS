## introdução

# O QUE É UM SISTEMA


Um sistema é um conjunto de partes que trabalham em conjunto para atingir um objetivo 

possui 3 etapas:

ENTRADA:
dados ou recursos que entram no sistema

PROCESSO:
transformação de dados em algo util

SAIDA:
resultado ou produto final

# O que é um Sistema de Informação

Sistema que coleta, armazena e distribui informações para apoiar decisões e controle em uma organização.

# O QUE É UM DADO

 Dado = fato bruto, sem contexto ou significado. por si só, o dado não diz nada.
 exemplo de dados brutos: 27
